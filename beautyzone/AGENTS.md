# BeautyZone

Next.js 16 (App Router) salon management app (Spanish UI), Prisma + local PostgreSQL, Tailwind v4. Package manager is **pnpm** (11.20.0); never npm/yarn.

## Commands

- `pnpm dev` / `pnpm build` / `pnpm start`
- `pnpm lint` — ESLint 9 (eslint-config-next). No typecheck or test scripts exist; verify with `pnpm exec tsc --noEmit` and the build.
- DB (Prisma): `pnpm db:generate` (generate client), `pnpm exec prisma migrate dev --name <slug>` (the `db:migrate` script is hardcoded to `init_beautyzone`), seed via `pnpm exec prisma db seed` → `pnpm dlx ts-node --compiler-options {"module":"CommonJS"} prisma/seed.ts` (only upserts roles 1–4).
- Requires local Postgres; `DATABASE_URL` lives in `.env` (gitignored).

## Layout & conventions

- Route groups in `src/app/`: `(auth)`, `(client)`, `(admin)`, `(recepcionist)`, `(stylist)`. Path alias is `@/*` → repo root, so imports are written `@/src/lib/db`, `@/src/app/services/...` — keep the `@/src` prefix; `@/lib/...` will not resolve.
- Data flow: Prisma queries in `src/app/services/*.service.ts` (client from `src/lib/db.ts`), server actions in `src/app/handlers/*.handler.ts` (`"use server"`), REST in `src/app/api/*/route.ts`, shared types in `src/app/types/`.
- Prisma models are Spanish-named (`Usuario`, `Cita`, `DetalleCita`, ...) mapped to snake_case tables via `@@map`. Enum-ish fields are plain strings with uppercase constants (`estado`: PENDIENTE/CONFIRMADA/...; `metodoPago`: EFECTIVO/TARJETA/TRANSFERENCIA). Role ids (seed): 1 Admin, 2 Cliente, 3 Estilista, 4 Recepcionista.
- Prisma CLI and `@prisma/client` are both at `5.22.0`. The previous `prisma@8.0.0-rc.13` (Prisma Next, contract-based) was removed — don't re-install it; the project uses the classic ORM workflow.

## Gotchas

- **Auth is plain-text**: `handleLogin` compares `user.password !== password`; no hashing lib installed. Don't add hashing without also migrating stored passwords.
- **Middleware vs localStorage mismatch**: `middleware.ts` guards `/admin/:path*` and `/reservas/:path*` off a `user_role` *cookie*, but login/register only write `localStorage` (`user`, `user_role`) — the cookie is never set. Assume middleware effectively redirects `/admin` out unless you also set the cookie.
- Legacy browser libs (jQuery, DataTables, flatpickr, Chart.js, SweetAlert2, jsPDF, XLSX, Tippy, Dropzone) load via CDN `<Script>` tags in `src/app/layout.tsx`; use the wrappers in `src/lib/sweetalert.ts` and `src/lib/exportUtils.ts` (`window.Swal` / `window.XLSX` / `window.jspdf`), not npm imports.
- Styling: Tailwind v4 (`@import "tailwindcss"` in `globals.css`). Theming colors come from `--sys-color-*` CSS variables in `globals.css`; fonts (Cormorant Garamond, Plus Jakarta Sans) via `next/font`.
- Uploads write to `public/uploads` via `src/app/api/upload/route.ts` (fs, not Cloudinary, despite next.config Cloudinary pattern).
